🚀 Project Overview

Traditional intrusion detection systems rely on static rules that can’t adapt to evolving threats.
This AI-Powered IDS uses trained machine learning models to analyze patterns in network data and automatically detect malicious activity — making it a smarter and more adaptive cybersecurity tool.

The Flask frontend provides a clean Application where users can:

Upload datasets (CSV / network logs)

Trigger real-time predictions

View results and threat classifications instantly


DEVELOPMENT ENVIRONMENT(Preffered)
Python 3.14
Flask 3.1
